# Conway's Game of Life

This is a simple implementation of Conway's Game of Life built with React and TypeScript.

## Features

- Start/stop simulation
- Clear the grid
- Select from predefined patterns:
  - Glider
  - Blinker
  - Beacon
  - Gosper Glider Gun
  - Pulsar
- Click on cells to toggle their state

## Development

This project was created using:
- React
- TypeScript
- Vite
